# 요가 (Android 요가 자세 코치 앱)

휴대폰 홈 화면 아이콘 이름: **요가**

카메라로 사람의 자세를 인식해 요가 기준 자세와 비교합니다. 부위별 점수(손·팔·다리·몸)와 종합 점수, 문제점, 개선 방법을 실시간으로 알려 줍니다.

## 주요 기능
| 기능 | 내용 |
|---|---|
| 동작 목록 | 입문 / 초급 / 중급 / 고급 탭, 17개 동작 (그림, 설명, 유지 시간) |
| 자세 겹쳐 보기 | 카메라 화면 위에 **흰색 반투명 기준 자세**를 사용자 몸 위치·크기에 맞춰 겹쳐 그림 |
| 사용자 골격 | 인식된 뼈대를 색으로 표시 (초록 좋음 / 노랑 보통 / 빨강 교정 필요) |
| 부위별 점수 | 손(위치·간격), 팔(팔꿈치 각도·위팔·아래팔 방향), 다리(무릎 각도·허벅지·정강이 방향), 몸(상체 기울기·고관절·머리·어깨선) |
| 종합 점수 | 부위 가중치 손 15 · 팔 25 · 다리 30 · 몸 30. 가장 나쁜 부위도 함께 반영 |
| 문제점 / 개선 방법 | 점수가 낮은 순서로 3개. 예) "왼쪽 무릎이 너무 굽어 있어요 (현재 154° / 목표 178°)" → "왼쪽 무릎을 더 펴 주세요" |
| 유지 시간 | 80점 이상을 유지한 시간을 세고, 목표 시간에 도달하면 완료 안내 |
| 음성 안내 | 가장 중요한 교정 사항을 6초마다 한국어 음성으로 안내 (켜기/끄기) |
| 좌우 자동 인식 | 왼쪽·오른쪽 어느 쪽으로 해도 맞는 방향을 자동으로 골라 채점 |

자세 인식은 Google ML Kit(Pose Detection)로 **휴대폰 안에서만** 처리합니다. 영상은 저장하거나 전송하지 않습니다.

## 동작 목록
| 단계 | 동작 |
|---|---|
| 입문 | 산 자세, 양팔 위로 뻗기, 서서 옆구리 늘리기, 의자 자세 |
| 초급 | 나무 자세, 전사 자세 2, 삼각 자세, 하이 런지 |
| 중급 | 전사 자세 3, 아래를 향한 개, 코브라, 브릿지, 보트 |
| 고급 | 반달 자세, 댄서 자세, 측면 플랭크, 까마귀 자세 |

## 1단계: 설치 파일(Yoga.apk) 만들기 — GitHub 자동 빌드
1. [github.com](https://github.com)에 가입하고 **+ → New repository**를 누릅니다.
   - 이름은 `yoga`로 하고, **Public**을 선택한 뒤 저장소를 만듭니다.
2. **uploading an existing file**을 눌러 이 폴더 **안의 파일·폴더 전부**를 끌어다 놓고 **Commit changes**를 누릅니다.
   - `.github` 폴더도 꼭 포함하세요.
3. **Actions** 탭에서 초록색 ✓가 뜰 때까지 기다립니다 (5~8분).
4. 완료되면 아래 주소에 휴대폰용 다운로드 링크가 생깁니다.
   `https://github.com/<내아이디>/yoga/releases/latest/download/Yoga.apk`

Android Studio로 직접 만들 수도 있습니다: **Build → Generate Signed Bundle/APK** 대신 **Build → Build APK(s)**를 누르면 고정 서명키로 서명된 APK가 만들어집니다.

## 2단계: 휴대폰에 설치 (인스톨)
1. 위 다운로드 주소를 휴대폰으로 보냅니다 (카카오톡 나에게 보내기 등).
   - APK 파일 자체를 보내도 됩니다.
2. 휴대폰에서 링크나 파일을 눌러 `Yoga.apk`를 받고 **설치**를 누릅니다.
   - "출처를 알 수 없는 앱" 경고가 나오면 **설정 → 이 출처 허용**을 켭니다.
   - Play 프로텍트 경고가 나오면 **무시하고 설치**를 누릅니다. 개인이 만든 앱이라 나오는 안내입니다.
3. 설치가 끝나면 **열기**를 누르거나, 앱 목록의 **요가** 아이콘을 누릅니다.
4. 처음 실행하면 "홈 화면에 바로가기를 추가할까요?" 창이 뜹니다. **[추가]**를 누르면 홈 화면에 **요가** 아이콘이 생깁니다.
5. 새 버전도 같은 방법으로 설치하면 기록이 유지된 채 덮어쓰기(업데이트)됩니다.

PC와 USB로 설치하려면 `tools\install_to_phone.bat`을 쓰세요 (Yoga.apk를 이 폴더에 둔 뒤 실행).

## 삭제 (언인스톨)
- **앱 안에서**: 오른쪽 위 ⋮ 메뉴 → **앱 삭제(언인스톨)** → 확인 → 삭제
- **휴대폰에서**: **요가** 아이콘을 길게 누름 → 앱 정보(ⓘ) 또는 삭제 → 삭제
- **PC에서**: `tools\uninstall_from_phone.bat`
- 앱을 삭제하면 홈 화면 바로가기도 함께 사라집니다.

## 사용 팁
- 휴대폰을 세로로 세워 허리 높이에 두고 **2~3m 뒤**에 서서 머리부터 발목까지 화면에 들어오게 하세요.
- 목록에 "옆으로 서기"라고 표시된 동작은 몸 옆면이, "정면 보기" 동작은 정면이 카메라를 향하게 하세요.
- 밝은 곳에서, 몸에 붙는 옷을 입으면 인식이 더 정확합니다.

## 동작 추가 / 수정
`app/src/main/assets/poses.json`만 고치면 됩니다.
- 각 동작은 13개 관절 좌표(`points`)로 기준 자세를 정의합니다. 골반 중심이 (0,0), 몸통 길이가 1이며 y는 아래쪽이 +입니다.
- 채점 기준(목표 각도·방향)은 이 좌표에서 자동으로 계산됩니다.

## 코드 구조
```
app/src/main/java/com/yogacoach/app/
├─ (.github/workflows/build-apk.yml  GitHub 자동 빌드, tools/ PC→휴대폰 설치·삭제 스크립트)
├─ model/        Model.kt (관절·좌표·동작), PoseRepository.kt (poses.json 읽기)
├─ scoring/      PoseScorer.kt  ← 채점·문제점·개선 방법 (안드로이드 비의존, 단위 테스트 있음)
├─ camera/       PoseAnalyzer.kt (CameraX → ML Kit 자세 인식)
└─ ui/           MainActivity(목록) · PracticeActivity(연습) · OverlayView(겹쳐 그리기) · PoseThumbView(자세 그림)
```

## 한계
- 2D 카메라 영상만으로 판단하므로, 카메라 방향과 비틀림(회전)은 정확히 알 수 없습니다.
- 바닥 자세(코브라, 브릿지, 까마귀)는 몸이 겹쳐 인식이 불안정할 수 있습니다.
- 운동 보조용이며 의료·재활 지도를 대신하지 않습니다. 통증이 있으면 즉시 멈추세요.
